# WiKo E-Tech V5 Final – Parallel 14 PCs + OneDrive ohne extra Dienst

Features:
- Parallel: 14 PCs können gleichzeitig arbeiten, jeder PC eigener Timer + eigene Sperre
- Pflicht Name vor Start, 20 Min Countdown, Auto-Abschluss, rot <5 Min
- Strenge Auswertung: Bei (n) müssen genau n richtige Kreuze, sonst 0 Punkte – kein Schummeln durch Alles-Ankreuzen
- IHK 100 Punkte: 100-92=1, 91-81=2, 80-67=3, 66-50=4, 49-30=5, 0-29=6, IHK bestanden ab 50%, internes Ziel 75% rot markiert
- Themenschwerpunkt: pro Thema % + Top 3 Schwächen rot mit Empfehlung für Ausarbeitung/Präsentation
- Azubi sieht nur eigenes Ergebnis + Themenschwerpunkt, kein Zugriff auf andere, kein Neustart
- Nach Abschluss Buttons: "Ergebnis in OneDrive speichern" (CSV WiKo_Name_Datum_Prozent.csv in gemeinsamen OneDrive Ordner) + "Ergebnis für Teams" (Datei für Teams Chat)
- Ausbilder PIN 9194: Volltabelle lokale Ergebnisse dieses PCs, Sammel-Excel Export für OneDrive, Nächsten Azubi freigeben, Alle löschen

Installation:
Inhalt in https://github.com/TheRealSancho/Wiko-Grundlagen-Elektrotechnik pushen, Pages aktivieren main/root
Live: https://therealsancho.github.io/Wiko-Grundlagen-Elektrotechnik/

OneDrive Workflow:
1. Gemeinsamen Ordner erstellen: OneDrive/Dokumente/WiKo-Ergebnisse (für alle 14 PCs freigeben)
2. Jeder Azubi speichert nach Test seine CSV dort
3. Ausbilder sieht alle 14 Dateien im eigenen OneDrive
