# WiKo Grundlagen Elektrotechnik

Interaktive Wissenskontrolle für Azubis – Mechatroniker

Live nach Pages Aktivierung: https://therealsancho.github.io/Wiko-Grundlagen-Elektrotechnik/

## Features
- Grundlagen (13 MC) + Fragenkatalog (251 TF)
- Modi: Grundlagen / Komplett / Kombi
- Fortschritt, Suche, Filter
- Auswertung erst nach "Test abschließen"
- Anzeige: Punktzahl, Prozent, Note, Detail-Liste aller falsch gesetzten Kreuze

## Installation auf GitHub https://github.com/TheRealSancho/Wiko-Grundlagen-Elektrotechnik
1. Inhalt dieses ZIPs ins Repo pushen
2. Settings > Pages > Source: main / root
3. Fertig
