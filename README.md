# WiKo E-Tech V2 – mit Timer, Sperre und Export

Features V2:
- Pflicht Namenseingabe (Vor+Nachname) vor Start
- 20 Minuten Countdown, Auto-Abschluss bei 0:00, bleibt bei Reload erhalten
- Nach Abschluss gesperrt – keine Änderungen mehr möglich
- Ergebnis mit Name, %, Schulnote (1: >=90%, 2: >=75%, 3: >=60%, 4: >=50%, sonst 5), Zeit
- Übersicht für max 14 Azubis + Excel/CSV Export

Installation:
1. Inhalt ins Repo https://github.com/TheRealSancho/Wiko-Grundlagen-Elektrotechnik pushen
2. Settings > Pages > Branch main / root
3. Live unter https://therealsancho.github.io/Wiko-Grundlagen-Elektrotechnik/

Der Export speichert: Nr, Name, Datum, Punkte, Gesamt, Prozent, Note, Dauer, Modus
